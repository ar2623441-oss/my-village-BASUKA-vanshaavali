About This Vanshaavali परिचय

This document preserves the genealogical history of the families of बसुका (Basuka) village. It is transcribed in full from the printed सकरवार वंशावली (Sakarwar Vanshaavali), pages 18 to 63, covering the mythological Rishi lineage down through पुरनमल राय and रतन देव राय, and branching into the राजशाह (पूरब पट्टी) and भोजशाह (पश्चिम पट्टी) lines of Basuka's भूमिहार families, as well as the सकरवार पठान branch.

Use the Family Tree tab to visualize generational connections. The Members tab lets you search any of the 1,500+ recorded individuals by name, ID, generation, or branch — click "View" to see a person's full ancestor chain and children. Village History holds the origin story.

Gotra & Kul गोत्र एवं कुल

Gotra is the patrilineal lineage traced back to a Vedic sage (Rishi). Every Hindu family belongs to one gotra. Marriage within the same gotra is traditionally prohibited (sapinda relationship).

This website is fully editable by you!

All data is stored directly in this index.html file. Open it in any text editor (VS Code recommended) and follow the guide below to add your real family data.

Step-by-Step Editing Guide

1. Correct or Add a Person

All 1,583 records live in data/basuka_vanshaavali.json, not in this HTML file. Open that file in VS Code and find the person by "nameHi" or "id". Each entry looks like this:

{ "id": "P1508", "nameHi": "रामदवर राय", "nameEn": "Ramdavar Rai",
  "fatherId": "P1505", "childrenIds": ["P1513","P1514","P1515","P1516"],
  "generation": 61, "branch": "राजशाह वंश — पूरब पट्टी (Raj Shah / Poorab Patti)",
  "lineEnds": false, "page": "61", "notes": "" }

To add a new person: give them a new unique id (e.g. "P1584"), set their fatherId to an existing person's id, and add their new id into that father's childrenIds list. Save the file — the website re-reads it automatically on refresh.

2. Edit Village History

Find <section id="history"> in index.html and replace the placeholder text with your actual village history.

3. Fix a Reading from the Original Book

The master Excel file (Basuka_Vanshaavali_MASTER.xlsx) has the same data in spreadsheet form with a "Legend & Notes" tab listing a few ambiguous readings still open for review. Once you confirm a correction there, mirror the change in data/basuka_vanshaavali.json.

4. See Your Changes Locally Before Pushing

Because this page loads data/basuka_vanshaavali.json with fetch(), opening index.html by double-clicking it won't work (browsers block local file fetches). In VS Code, install the Live Server extension, right-click index.html, and choose "Open with Live Server."

5. Publish to GitHub Pages

Your repository is ar2623441-oss/my-village-BASUKA-vanshaavali. Once index.html and the data/ folder are pushed to the main branch, go to Settings → Pages, set Source: Deploy from a branch, branch main, folder / (root), and save. The site will be live at:

https://ar2623441-oss.github.io/my-village-BASUKA-vanshaavali/

6. Add Photos

Create a photos/ folder in the repo, upload images there, and reference them from a person's profile by extending that person's JSON entry, e.g. "photo": "photos/name.jpg".

7. Custom Domain (Optional, ~₹500/year)

Buy a domain like basuka-vanshavali.in, then point it to your GitHub Pages site under Settings → Pages → Custom domain.
